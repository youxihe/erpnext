# POC-03 — 国内 PC 导航与角色工作台

## 目标
保留 ERPNext 原生单据和操作能力，但让普通国内员工习惯**左侧菜单导航 + 右侧业务区**，不需要认识大量英文模块和完整 ERPNext 导航。

## 信息架构（一级菜单）
1. 工作台：我的任务、待办、逾期订单、订单摘要。
2. 客户与销售：客户记录/报备（先基础客户记录）、销售订单、交付和回款查看。
3. 设计与生产：BOM、生产计划、生产工单、车间任务(Job Card)。
4. 采购管理：物料需求、采购订单、采购入库、供应商。
5. 仓库管理：库存查询、入库、出库、领料、产成品入库。
6. 物流交付：交货单、交付状态；不开发复杂物流。
7. 财务管理：销售开票、收款、采购发票、付款；不新增中国税务系统。
8. 经营报表：订单、交期、物料成本；没有真实统计口径则标尚未适配。
9. 基础资料：物料、仓库、客户、供应商、员工。
10. 系统设置：用户、角色、必要参数；非管理员隐藏。

## 执行
1. 先验证 Frappe v16 自带 Workspace、工作台快捷入口、自定义侧边栏/页面/快捷方式能力；优先**配置**，不得一开始重写完整 Vue 前端。
2. 实现主要菜单中文化和左栏持续可见、右侧单据打开；不允许打开一个菜单不断新开浏览器 tab、出现空白页或 404。
3. 无关模块如 HR、资产、网站、CRM 全功能、质量复杂设置等从普通角色的导航隐藏，**不得为了隐藏菜单删除 DocType 或关闭必要的 ERP 依赖**。
4. 至少设置并测试：销售、设计、采购、仓库、车间、财务、管理 7 个角色/权限画像。POC 可仅建 3-4 个真实登录用户复测关键菜单，但证明其它角色有正确菜单设计。车间只见自己的任务，销售仅在其权限范围查看；界面隐藏并不等于服务端授权，必须验证后台权限。
5. 如果 ERPNext 原生侧栏不能满足固定左侧菜单+右侧区域，记录差异；先做**最小自有扩展**来补，防止对 Desk 核心做大面积修改。可用独立 Frappe app；如新建其他仓库须先记录位置并取得用户批准。临时 POC 代码可以纳入本仓隔离目录，但不能误认为它自动安装到了站点。
6. 菜单配置应可导出/恢复（Workspace/Role/fixture），提供用户使用导航图，截图及实测路径。

## DoD
- 核心菜单清晰、中文、侧边导航稳定、右侧内容可用。
- 3 个不同角色实际登录证明菜单/权限差异；非管理员不可直接通过 URL 越权。
- 记录复现方法和证据 docs/poc/evidence/POC-03-navigation.md。
