# POC-02 — 简体中文默认界面

## 目标
国内用户开箱可用、默认简体中文，而不只是管理员账号切换一次语言。

## 执行
1. 系统设置默认语言为**简体中文**。具体内部语言代码必须从实际 Language 表确认（例如 zh，而非凭空假定 zh-CN）；默认区域 China、货币 CNY、时区 Asia/Shanghai、日期 YYYY-MM-DD。
2. 明确 Frappe 优先读取 User.language，再回退 System Settings.language；分别验证 Administrator、新创建的销售/车间用户、新浏览器会话，确保登录刷新后仍为中文；用户主动改英文可生效，不锁死个人选择。
3. 检查工作台、菜单、销售单、客户、物料、BOM、生产工单、Job Card、领料、采购单、仓库、发票/付款主要字段与按钮的中文效果；记录中英混排，优先配置/翻译覆盖，不批量修改 ERPNext 上游 JSON/PO。
4. 特别检查 v16 中文翻译版本兼容与升级回退问题；已知 Frappe 16 曾有 zh 翻译回退故障报告，不能只看 Language 代码已保存。若译文缺失，记录准确场景、版本及可重复覆盖方案，不瞒报。
5. 将可重放的配置步骤或自有 app fixtures / patch 纳入版本管理；提供 3 张以上中文页面证据（工作台、销售订单、生产任务）。

## DoD
- 新用户默认中文，登录刷新仍中文；关键流程按钮有中文可读标签。
- 翻译缺口形成清单，影响 POC 的关键字段必须修复，否则 BLOCKED。
- 提交复现配置与截图/记录到 docs/poc/evidence/POC-02-l10n.md。
