## 四类订单
1. 生产类：设备装配 X1（库存产成品，需 BOM）×2 台，建议销售价 8800 元/台；承诺交付日在演示日期之后。
   - 每台 BOM：装配机架 ×2 件，传感器 ×1 件，紧固件 ×4 件。
   - 对应原料初始：机架 1 件、传感器 0 件、紧固件 12 件。两台需求：机架 4、传感器 2、紧固件 8；机架缺 3，传感器缺 2。必须通过真实采购入库填补，采购实测数量与单据要核对。单价示例：机架200、传感器300、紧固件5（以录入结果为准）。
   - 至少两道工序：装配、检验；对应负责人和计划/实际时间。
2. 耗材类：过滤耗材包 ×10 包，库存可用不少于 10，销售单直接创建交货单、扣减库存，无制造。
3. 零部件类：替换法兰组件 ×5 件，库存可用不足时正常补采购后交货；无制造。
4. 服务类：设备安装服务 ×1 次，作为非库存服务 Item，单价可录入，但不得自动扣减任何库存、不得创建 BOM/工单。

## 可复现
- 先新建干净的 POC site 后导入；不要污染其他环境。
- 演示库存来自采购入库/Stock Reconciliation（仅初始化期可用，需审计并记录）；生命周期中的新增库存必须用业务单据。用初始化 Stock Reconciliation 与实际采购行为区别标明。
- 不要把所有假设都当作已符合客户业务。采购多订单合并、订单行混合类型、按订单个性化 BOM、生产任务简化等是本 POC 需要评估的差异。
- 业务数据脚本必须有幂等控制（例如按 external test key、业务名称和存在性检查），可直接在 PC 页面手工操作，但交接必须包含逐字段步骤或自动初始化工具。
