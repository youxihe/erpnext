## 状态语义
- TODO：尚未操作。
- LOCAL_PASS：本地站点/Mock/测试通道已测通，但不是企业微信真人 UAT。
- REAL_WECOM_PASS：真人在企业微信自建应用或真实 API Bot 操作，对账 ERP 同一数据并留下证据。
- FAIL：实测未达到标准。
- BLOCKED：缺少企业微信授权、合法可信域名、Bot 权限或其他无法由 Workbuddy 解决的资源。
